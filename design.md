## Brand & Style

This design system channels an intellectual, serene, and deliberate atmosphere reminiscent of scholarly tools, modern research labs, and contemplative digital studios. The visual character pairs restraint with literary polish, treating the user interface as a quiet, physical parchment rendered in dark matte minerals rather than artificial glow.

Key brand pillars:
- **Quiet Authority:** Interactions are calm, precise, and confident. Content and typography take precedence over ornamentation.
- **Warm Tactility:** Surfaces evoke espresso-washed paper, charcoal slate, and cast iron rather than stark digital blacks, eliminating visual fatigue.
- **Editorial Distinction:** Rich editorial serif headlines paired with razor-sharp modernist grotesk text and monospaced catalog markers evoke high-end print design and considered craft.
- **Intentional Warmth:** A restrained terracotta and ember accent system introduces singular, purposeful focal points without disrupting the contemplative, museum-like environment.

## Colors

The palette is anchored in warm obsidian and espresso-slate tones, moving away from cool blues or sterile synthetic neutrals. Contrast is achieved through delicate gradations of warm stone and bone whites.

### Palette Architecture
- **Canvas Base (`#181816`):** Deep charcoal slate with an underlying espresso cast. Provides maximum readability without harsh ocular stress.
- **Surface Elevation 1 (`#20201D`):** Elevated panels, side navigation rails, and backdrop containers.
- **Surface Elevation 2 (`#262624`):** Interactive cards, code surfaces, popovers, and floating toolbars.
- **Surface Elevation 3 (`#2E2E2A`):** Active card highlights, hovered items, and embedded pills.
- **Subtle Stroke (`#333330`):** Fine hairline borders, baseline dividers, and structural framing.
- **Primary Text (`#E8E6DF`):** Soft parchment white with balanced warmth, providing high legibility.
- **Secondary Text (`#9E9C94`):** Muted stone gray for supporting narrative, metadata, and structural indices.
- **Tertiary Text / Dim (`#6E6C65`):** Subtle captions, disabled states, and inactive icons.
- **Primary Accent (`#D97757`):** Refined terracotta/coral used strictly for semantic actions, active indicators, and critical links.
- **Warm Highlight (`#E0A368`):** Soft honeyed amber reserved for status badges, inline callouts, and cursor states.

## Typography

The typography system sets up a deliberate dialogue between three font families:

- **Editorial Voice (Newsreader):** Headlines and key narrative callouts utilize optical sizes and traditional serif geometry to introduce an essayistic, literary weight. Headings lean toward lighter and regular weights (`400`) to retain elegance.
- **Reading Engine (Hanken Grotesk):** Body narrative and primary UI text rely on a sharp, contemporary neo-grotesk with open counters and balanced geometry, ensuring crisp clarity on dark backgrounds.
- **Catalog & Metadata (JetBrains Mono):** Dates, case study indices, tags, status metrics, and navigational numbers use a calibrated monospaced typeface set in modest sizes with expanded letter-spacing.

## Layout & Spacing

The layout is grounded in an asymmetrical, editorial grid system designed to let long-form projects, documentation, and imagery breathe:

- **Desktop (1024px+):** 12-column responsive layout capped at a maximum width of `1320px`. Generous canvas margins (`4rem`) frame the workspace. Off-center column splits (e.g., 4 columns for project context, 8 columns for narrative and interactive media) emphasize editorial asymmetry.
- **Tablet (768px - 1023px):** 8-column layout with `2rem` margins and `1.25rem` gutters. Secondary details fold below hero displays.
- **Mobile (< 768px):** 4-column layout with `1.25rem` margins and `1rem` gutters. Structural frames collapse vertically into single-column tracks.
- **Rhythm:** Spacing follows an 8-point base scale with a 4-point micro-modifier. Card interiors maintain generous breathing room (`space-lg` to `space-xl`), allowing high information density without visual clutter.

## Elevation & Depth

This design system avoids heavy drop shadows and synthetic neon diffusion in favor of **tonal layering** and **delicate physical boundaries**:

- **Tonal Stepping:** Elevation is communicated purely through value increments: base `#181816` moves to container `#20201D`, card `#262624`, and raised overlay `#2E2E2A`.
- **Hairline Outlines:** Surfaces are delineated by crisp 1px borders colored in subtle stone `#333330` at `100%` opacity or `#E8E6DF` at `6%` opacity. Borders reinforce structure without creating grid visual noise.
- **Atmospheric Floor Shadow:** Floating dialogs, command palettes, and modal sheets receive an ambient, diffuse shadow tinted warm-black: `0 20px 48px -12px rgba(10, 10, 9, 0.65)`.
- **Optical Inset:** Inner borders (`box-shadow: inset 0 1px 0 0 rgba(232, 230, 223, 0.05)`) provide high-end, etched glass-like top edges on dark cards.

## Shapes

The shape system adopts a **soft, architectural restraint** (`roundedness: 1`):

- Default interactive elements (buttons, inputs, tags) utilize `0.25rem` (4px) radii.
- Medium components (case cards, dialogue panels, callout boxes) use `rounded-lg` at `0.5rem` (8px).
- Modals, large image viewports, and primary showcase blocks use `rounded-xl` at `0.75rem` (12px).
- Pill shapes are intentionally avoided except for circular status dots and select micro-badges, preserving the system's structured, printed-manuscript aesthetic.

## Components

### Buttons
- **Primary:** Filled with warm terracotta `#D97757`, text in `#181816` (bold for contrast), subtle hover shift to `#C96442`. No drop shadow; sharp 4px corners.
- **Secondary / Outline:** Background transparent, border 1px `#333330`, text in `#E8E6DF`. On hover, background shifts to `#262624` with border brightening to `#444440`.
- **Ghost:** Text in `#9E9C94`, transitioning to `#E8E6DF` with a subtle `#20201D` background on hover.

### Chips & Tags
- Set in `label-sm` (JetBrains Mono).
- Background `#20201D`, border 1px `#333330`, text `#9E9C94`.
- Active or highlighted tags feature text in warm terracotta `#D97757` with an accent dot indicator in `#D97757`.

### Cards & Project Showcases
- Surface background `#262624`, encased with a 1px `#333330` hairline boundary.
- Generous internal padding (`space-lg`).
- Interactive hover states avoid vertical lift; instead, the border brightens slightly toward `#4A4A45` alongside an subtle increase in internal background brightness to `#2A2A28`.

### Input Fields & Search (Command Bar)
- Background `#20201D`, hairline border 1px `#333330`, text `#E8E6DF`, placeholder in `#6E6C65`.
- Focus state replaces the border with `#D97757` without aggressive glow, relying on a clean, single-pixel warm border transition.

### Checkboxes & Radio Controls
- Base box `#20201D` with 1px border `#333330`.
- Selected state fills with `#D97757`, using `#181816` for the check mark/dot. Radii remain strictly angular (2px for checkboxes, full circle for radios).

### Lists & Index Rows
- Editorial index rows use subtle border-bottom dividers in `#333330`.
- Left-aligned monospace index numbers (`01`, `02`) in `#6E6C65`, followed by Newsreader project titles that transition smoothly to `#D97757` on row hover.
